# The Scaffold Continuity Trap

**The Scaffold Continuity Trap: A Blinded Scaffold-Lesion Test in Persistent Coding Agents**

Thomas Ryan, 2026.

Zenodo DOI: https://doi.org/10.5281/zenodo.21342748

## Summary

This preprint tests whether continuity-like behavior in persistent coding agents is carried by external scaffolds such as project files, tests, handoff notes, summaries, tool traces, and control state.

The preregistered build claim was not supported in the straight-condition fixture. Four separate blinded runner threads completed full scaffold, summary-only, no-memory, and sham-lesion packets. All four reached 12/12 on the core continuation score, so full scaffold did not outperform no-memory or summary-only. The supported conclusion is narrower: in small coding-continuation tasks, ordinary visible repository state and tests can carry enough task-local causal structure for perfect action-level recovery even when richer continuity scaffolds are removed.

This result does not test or claim AI consciousness, personhood, moral status, survival, subjective continuity, or internal persistence of a base model.
