## Missing evidence required before empirical claims

| Gate | Evidence not present | Consequence |
|---|---|---|
| Exact snapshot eligibility | Provider/model-free eligibility proof for every requested exact model identity | No empirical panel is frozen. |
| Task adequacy | Per-snapshot accuracy, format validity, latency, and ceiling/floor checks | Unsaturation is unknown. |
| Choice positivity | Baseline low/high support inside every fine stratum | Retained block counts and feasibility are unknown. |
| Provider transport | Exact tool-loop, retry-zero, routing, fallback, and failure behavior | Request and failure projections remain conditional. |
| Cost | Exact prices, token caps, caching, tool fees, failed-request billing | No dollar envelope is licensed. |
| Mechanism comparator | Semantically audited burden-neutral credibility manipulation | Workload-specific mechanism remains unidentified. |
| Randomized execution failure | A tested standalone draft authority exists, but its terminal-disposition taxonomy and exactly-once ledger are not integrated into the production state machine, runner, persistence, recovery, schema, analyzer, or sealed manifest; amended inference is not recertified. | Complete-path sizing cannot authorize collection. |
| Assignment/exposure integration | A tested draft binds the 576-member allowed set and selection proof, but production full-row joins, exposure reconstruction, assignment-engine binding, and entropy generation/timing/custody are not frozen and integrated. | Assignment membership and selection cannot yet be established for a collected block. |
| Dependence recertification | The non-gating screen covers only declared synthetic profiles and explicitly has no gate effect; the full restricted donor-yoke, failure, provider/batch, temporal, formation, boundary, resource, and selection grid is not sealed. | `B=384` remains conditional illustrative sizing. |
| Inference implementation | The enumerated statistical choices are amendment-frozen, but production analyzer/report integration, amended recertification, registration/seal, binary-bound uncertainty, and attempt/stopping/deviation policy remain unresolved. | The amendment decisions cannot yet govern collected data. |
| Preregistration and decision authority | Registered Report and decision-charter drafts exist, but unresolved fields remain and neither authority is preregistered, independently approved, production-implemented, or sealed. | Draft text cannot govern collection or analysis. |
| Literature update | Rerun and archive the searched record at protocol freeze | Priority wording remains provisional. |
| Confirmatory freeze | Immutable prompts, allocations, parsers, run ID, manifest digest, and approved action | Calibration cannot become confirmation. |
