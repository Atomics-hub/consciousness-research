## Description

An AI system can select an action without its later behavior depending on
whether that selection actually controlled what happened. This methods and
feasibility preprint introduces the Binding Test, a block-yoked randomized
design for estimating whether later terminal choice outputs change when an
earlier choice controls an assigned history rather than being paired with an
assigned-schedule-matched yoke.

The release separates three evidence layers. A sealed zero-call construction
audit establishes deterministic item, assignment, state-machine, and analytic
identification properties. Seeded synthetic calculations examine conditional
operating characteristics and identify support formation as a major planning
risk. One sealed exploratory Claude Code trajectory demonstrates that the exact
visible three-turn workflow can complete with mechanically valid output. A
separate route observation exposed two provider-reported model identities in
one visible turn and no observable raw-HTTP count.

The provider evidence is not calibration, randomized evidence, an effect
estimate, or confirmatory data. The paper does not establish model preference,
utility, welfare, suffering, consciousness, sentience, or subjective
experience. A future confirmatory test requires a separately frozen and
preregistered production protocol.
